# Third-Party Notices

This project began with browser-backed web tooling from
[antirez/ds4](https://github.com/antirez/ds4) and includes or is derived in part
from ideas and implementation from that project.

The initial `chrome-web-mcp` package baseline was established under the
`kuraneko1` name. The visible Git history also records subsequent work under
the names `ryu` and `_ryu15_`. The browser-backed tooling was subsequently
substantially reworked for Python and the Model Context Protocol (MCP), and
the current repository includes a separate Windows runtime.

This file preserves the upstream notice so that the origin and applicable
license terms remain clear. The current project is a substantial reimplementation
based on that starting point, not the original `ds4` project.

This is an independent Windows-focused repository. Please direct support
questions and Windows-specific bug reports to this repository's Issues rather
than to the upstream projects.
